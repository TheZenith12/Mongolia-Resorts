# Монгол Нутаг

Монгол орны амралт, аялалын газруудыг нэгтгэсэн платформ — байгалийн үзэсгэлэнт газар, амралтын газруудыг нэг дороос харж, захиалж, төлбөрөө хийх боломжтой.

Энэ төслийг би ганцаараа, бие даан судалж хөгжүүлсэн. Ажлын явцад Next.js App Router, MongoDB/Mongoose дата загварчлал, NextAuth-аар authentication, Cloudinary-аар зургийн хадгалалт, QPay/Stripe-аар онлайн төлбөр зэргийг бодит систем дээр гараар дадлагажин сурсан. Хамгийн их цаг зарцуулсан хэсэг нь backend болон admin тал байсан — role-д суурилсан эрхийн систем (super admin, manager, user, guest), захиалгын урсгал, төлбөрийн интеграц зэргийг цоо шинээр, гаднын бэлэн шийдэлгүйгээр бүтээсэн.

Frontend-ээс backend хүртэл, дата загвар, authentication, төлбөрийн систем хүртэл бүх хэсгийг ганцаараа хийж дуусгасан бүрэн бүтэн (full-stack) систем.

## Технологи

- **Next.js 14** (App Router, Server Actions)
- **MongoDB** + Mongoose
- **NextAuth.js v4** — credentials auth, JWT
- **Cloudinary** — зургийн хадгалалт
- **QPay / Stripe** — төлбөр
- **Tailwind CSS**
- **Vercel** — deploy
